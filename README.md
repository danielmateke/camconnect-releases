# CamConnect — Téléchargements

Téléchargements officiels de l'application **CamConnect**,
l'application camerounaise tout-en-un.

## Télécharger la dernière version

**[Télécharger camconnect.apk](https://github.com/danielmateke/camconnect-releases/releases/latest/download/camconnect.apk)**

Ou consultez toutes les versions dans l'onglet
[Releases](https://github.com/danielmateke/camconnect-releases/releases).

## Installation
1. Téléchargez le fichier `camconnect.apk`.
2. Ouvrez-le — autorisez « Installer des applications inconnues » si demandé.
3. Lancez CamConnect et créez votre compte.
